---
name: DoinkSports access decision
description: Permission boundary for using DoinkSports as a BetCouncil source
---

Do not automate or build a production dependency on DoinkSports unless Doink grants explicit written programmatic-use permission.

**Why:** The service is undocumented and DoinkSports' terms prohibit automated or non-human access. Public technical reachability is not an API license or redistribution grant.

**How to apply:** Before adding a fetcher, workflow, or connector, obtain permission that defines allowed routes, rates, storage, and redistribution. Otherwise use licensed upstream providers.
